# Veritrace — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Learner

- As a learner, I want my activity traces stored in my chosen repository, so that the learning platform is not a permanent panoptic store of my behaviour.
- As a learner, I want to grant a researcher time-boxed access for a stated study, so that voluntary research participation remains under my control.
- As a learner, I want to revoke access and request deletion of raw blocks, so that I can exercise GDPR-style rights without chasing email threads.

### Education researcher

- As a researcher, I want integrity verification on every retrieved block, so that analyses are not poisoned by silent edits after the activity.
- As a researcher, I want a consent artefact attached to the export, so that ethics review can see purpose and time box.
- As a researcher, I want clear failure when a repository is offline or a hash mismatches, so that I do not treat missing data as valid empty activity.

### Teacher / learning-space owner

- As a teacher, I want research collection enabled only for spaces where learners opted in, so that classroom activity is not silently enrolled into studies.
- As a teacher, I want no extra blockchain jargon in the default UI, so that class time is not spent on wallets.

### Privacy officer

- As a privacy officer, I want proof that raw traces are not on chain, so that DPIAs can pass.
- As a privacy officer, I want a recorded decision when anchoring is disabled because a trusted party or single-writer pattern makes blockchain unnecessary, so that we do not pay fees for theatre.

### Platform administrator

- As a platform administrator, I want pluggable LBR and ledger adapters, so that institutions can choose self-hosted repos vs managed ones.
- As a platform administrator, I want tamper events to page security, so that integrity failures are operational incidents.
